SMS Scam Detector

A web platform for identifying and reporting scams in Kenya.

## Features
- Instant scam/safe message prediction
- Community scam reporting (device & in-person)
- Location tagging for in-person scams
- Admin panel

## Built With
- Python / Flask
- SQLite
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Install dependencies: pip install -r requirements.txt
3. Run: python app.py
4. Open: http://localhost:5000
